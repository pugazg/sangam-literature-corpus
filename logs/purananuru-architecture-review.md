# Puṟanāṉūṟu architecture review

- Shared infrastructure: preservation, normalization, manifests, schema, fidelity hashing, physical auditing, and regression comparison.
- Source-specific parser: flat Markdown/text export with labelled heading metadata.
- Structural strategy: eight mechanical fifty-poem ranges because no source divisions are printed.
- Source-derived fields: topical title, poet, addressee, tiṇai, tuṟai, loss statement, and dot lacunae.
- Null fields: controlled speaker and any metadata not explicitly printed.
- Printed anomalies remain verbatim; no reconstruction or silent correction is permitted.
