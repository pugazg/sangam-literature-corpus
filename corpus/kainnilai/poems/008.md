# கைந்நிலை 8

கருங்கை கதவேழம் கார்ப்பாம்புக் குப்பங்
கி...க்...கொண்...கரும்
பெருங்கல் மலைநாடன் பேணி வரினே
சுருங்கும் இவள்உற்ற நோய்.

## Source note (as printed)

(துறை :: தலைவி வேறுபாடு கண்டு வினவிய செவிலிக்குத் தோழி அறத்தோடு நிற்றல்.)
