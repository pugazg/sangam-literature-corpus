# திருக்குறள் 232

# திருக்குறள் 233

# திருக்குறள் 234

# திருக்குறள் 235

வித்தகர்க் கல்லால் அரிது.

# திருக்குறள் 236

# திருக்குறள் 237

# திருக்குறள் 238

எச்சம் பெறாஅ விடின்.

# திருக்குறள் 239
