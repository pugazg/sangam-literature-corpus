# புறநானூறு 317

வென்வேல் .. .. .. .. .. .. நது
முன்றில் கிடந்த பெருங்களி யாளற்கு
அதளுண் டாயினும், பாய்உண்டு ஆயினும்,
யாதுண்டு ஆயினும், கொடுமின் வல்லே;
வேட்கை மீளப .. .. .. .. .. ..
.. .. .. .. கும், எமக்கும், பிறர்க்கும்,
யார்க்கும், ஈய்ந்து, துயில்ஏற் பினனே.
