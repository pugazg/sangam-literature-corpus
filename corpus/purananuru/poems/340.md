# புறநானூறு 340

அணித்தழை நுடங்க ஓடி, மணிப்பொறிக்
குரலம் குன்றி கொள்ளும் இளையோள்,
மாமகள் .. .. .. .. .. ..
.. .. .. ..லென வினவுதி, கேள், நீ
எடுப்பவெ .. .. .. .. .. .. ..
.. .. .. .. .. மைந்தர் தந்தை
இரும்பனை அன்ன பெருங்கை யானை
கரந்தையஞ் செறுவின் பெயர்க்கும்
பெருந்தகை மன்னர்க்கு வரைந்திருந் தனனே.
