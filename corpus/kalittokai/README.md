# Kalittokai / கலித்தொகை

Status: formally frozen. Corpus schema version: **1.0.0**.

The canonical source is Project Madurai `pmuni0221`,
`https://www.projectmadurai.org/pm_etexts/utf8/pmuni0221.html`. The preserved
exact HTTP HTML response has SHA-256
`da4b2182fca2066c3627f6c9207a01748e8e9fe75d005995d5cbb7397a263195`.

The source encodes exactly 150 poems as table rows. Poem 1 is the printed
`கடவுள் வாழ்த்து`; poems 2–150 occupy five source-printed kali divisions.
The division headings and their printed author attributions are provenance
qualified. No poem-level speaker or tiṇai value is inferred.

Six section files preserve this source structure. They are aggregations, not
additional canonical records. Printed dot sequences in poems 114 and 131 are
preserved and classified as lacuna evidence; no reconstruction is supplied.
External comparison belongs only in `apparatus/kalittokai/`.

Version 1.0.0 freezes the selected source identity and checksum, records 1–150,
canonical bodies, printed lacunae, source divisions and attributions,
provenance representation, and validation expectations. It does not assert
that Project Madurai is a critical edition.
