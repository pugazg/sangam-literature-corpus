# பதிற்றுப்பத்து (Patiṟṟuppattu)

Status: **frozen**  
Corpus schema version: **1.0.0**

Canonical source: Project Madurai `pmuni0038`, preserved as an exact HTML response body.

The source contains eighty numbered surviving records, `11–90`, arranged in eight printed பத்து groups (2–9). It explicitly marks the first and tenth groups unavailable. The corpus does not manufacture records `1–10` or `91–100`.

Printed group-level ruler and poet statements are provenance-qualified. Poem-level துறை, வண்ணம், தூக்கு and பெயர் metadata are preserved as source notes. Printed பதிகம் blocks and the recovered fragments following the tenth-group loss notice remain in `structure-inventory.json`, outside canonical numbered poem bodies.

The eight section files reproduce source-printed surviving பத்து membership; they are not arbitrary mechanical ranges.

Version 1.0.0 freezes `pmuni0038`, its checksum, records 11–90, the eight surviving group assignments, explicit loss of groups 1 and 10, பதிகம் and recovered-fragment separation, canonical bodies, source notes and provenance. It does not reconstruct the lost groups or claim a critical edition.
