# திணைமாலை நூற்றைம்பது (Tiṇaimālai Nūṟṟaimpatu)

Formally frozen as corpus schema version `1.0.0`.

This is a source-faithful transcription of Project Madurai `pmuni0056`. The
source prints 153 numbered records despite the nominal 150 in the title. Its
five printed tiṇai divisions contain 31, 31, 30, 31, and 30 records. The
concluding unnumbered `சிறப்புப் பாயிரம்` is preserved at work level and is not
promoted to a numbered record. Printed structural prose is not mapped to an
inferred speaker field.
