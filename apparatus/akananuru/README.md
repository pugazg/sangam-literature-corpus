# Akanāṉūṟu editorial apparatus

This directory is separate from the canonical Project Madurai transcription. The canonical source is the complete source-only `pmuni0229` release. Later Project Madurai commentary editions are not merged into poem bodies or source-explicit metadata.

The apparatus currently records source selection and unresolved printed conditions only. It contains no preferred readings and performs no speaker, tiṇai, poet, historical, or literary inference.
