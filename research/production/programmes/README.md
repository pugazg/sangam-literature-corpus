# Classical Tamil production programmes

This planning tree gives every named work its own production folder and completion gate.

- எட்டுத்தொகை: 8 independent work folders.
- பத்துப்பாட்டு: 10 independent long-work folders. The immutable preservation source remains `corpus/pattuppattu`, but production must never treat the ten poems as one reviewed work.
- பதினெண்கீழ்க்கணக்கு: 18 independent work folders. These are planned only and are not activated by this R2 change.

The exact 29-dimension evidence contract, source-first review, provenance separation, reviewed-empty semantics and prohibition on Tolkāppiyam auto-classification apply to every future unit. R3 remains blocked.
